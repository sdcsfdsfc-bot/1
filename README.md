# 숲의 나방 · 유전 알고리즘 실험실

HTML, CSS, JavaScript만으로 실행되는 정적 웹사이트입니다. `index.html`을 열면 **해 찾는 과정**에서 평가·선택·교차·변이의 실제 계산값을 장면별로 살펴보고, **전체 그림**에서 12마리 개체군과 세대별 점수를 볼 수 있습니다. Python, Tkinter, 별도 서버나 빌드 과정은 필요하지 않습니다.

## GitHub Pages 게시

1. 이 폴더의 `index.html`, `styles.css`, `polish.css`, `trace.css`, `app.js`, `.nojekyll`을 GitHub 저장소의 기본 브랜치 루트에 올립니다. Git으로 폴더 전체를 올리는 경우 `.gitignore`가 원본 `1.py`를 제외합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 기본 브랜치와 **/(root)**를 선택해 저장합니다.
4. Pages 화면에 표시되는 주소에서 사이트를 엽니다.

기존 `1.py`는 로컬 원본 보관용이며 웹사이트 실행에 쓰이지 않습니다.
