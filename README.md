# 숲의 나방 · 유전 알고리즘 실험실

HTML, CSS, JavaScript만으로 실행되는 정적 웹사이트입니다. `index.html`을 열면 세 학습 파트를 볼 수 있습니다. Python, Tkinter, 별도 서버나 빌드 과정은 필요하지 않습니다.

## 학습 흐름

1. **후보 해와 한 세대:** 19개 고정 장면에서 문제, 후보 해, 평가, 부모 선택, 교차, 변이, 세대 교체를 네 예시로 살펴봅니다.
2. **선택 확률과 다양성:** 20개 고정 장면에서 높은 점수의 이점, 낮은 점수에도 남은 기회, 교차와 변이, 최고 해 보존을 학습합니다.
3. **내가 직접 실험하기:** 새 숲과 나방을 무작위로 만들고 변이 확률을 바꾸며 진행합니다. `해 찾는 과정`은 실제 계산을, `전체 그림`은 숲과 점수 그래프를 보여줍니다.

고정 예시는 하나의 대표 나무껍질 색으로 계산합니다. 자유 실험은 같은 숲의 여러 표본 지점을 모든 나방에 적용하여 공정하게 비교합니다. 두 경우 모두 위장 점수식은 같습니다.

이 점수식은 교육용으로 정한 규칙입니다. 반점 수는 유전되지만 현재 위장 점수에는 쓰이지 않으며, 10세대 결과가 전역 최적해라는 보장은 없습니다.

## GitHub Pages 게시

1. 이 폴더의 `index.html`, `styles.css`, `polish.css`, `trace.css`, `tutorial.css`, `app.js`, `tutorial.js`, `.nojekyll`을 GitHub 저장소의 기본 브랜치 루트에 올립니다. Git으로 폴더 전체를 올리는 경우 `.gitignore`가 원본 `1.py`를 제외합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 기본 브랜치와 **/(root)**를 선택해 저장합니다.
4. Pages 화면에 표시되는 주소에서 사이트를 엽니다.

기존 `1.py`는 로컬 원본 보관용이며 웹사이트 실행에 쓰이지 않습니다.
