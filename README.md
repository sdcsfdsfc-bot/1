# 숲의 나방 · 무늬 진화 실험실

HTML, CSS, JavaScript만으로 실행되는 GitHub Pages용 교육 사이트입니다. `index.html`을 열면 네 학습 파트를 볼 수 있습니다. Python, Tkinter, 빌드 과정은 필요하지 않습니다.

## 학습 흐름

1. **후보 해와 한 세대:** 고정된 나무껍질 위에서 12마리의 무늬를 비교합니다. 16개 장면에서 유전자, 무늬 생성, 평가, 부모 선택, 교차, 변이, 세대 교체를 따라갑니다.
2. **선택 확률과 다양성:** 6개 장면에서 무엇이 유전되는지, 색을 어떻게 섞는지, 변이가 왜 항상 유리하지 않은지 살펴봅니다.
3. **교차·변이 자세히:** 실제 숫자 유전자의 평가, 부모 선택 확률, 부모별 혼합 비율, 변이 전후의 무늬를 장면별로 확인합니다.
4. **내가 직접 실험하기:** 한 버튼으로 한 세대를 진행하거나 자동으로 진화시킵니다. 숲과 최근 점수 그래프만 보며 나무 색·무늬를 바꿀 수 있습니다. 새 배경에서도 기존 나방의 유전자는 유지하고, 점수와 세대 그래프를 새 환경 기준으로 다시 시작합니다.

## 유전자와 무늬

한 나방은 숫자 유전자 12개를 가집니다.

| 유전자 | 수 | 역할 |
| --- | ---: | --- |
| 바탕색 L*a*b* | 3 | 날개의 바탕색 |
| 무늬색 L*a*b* | 3 | 날개에 나타나는 무늬색 |
| 무늬 종류 | 1 | 미리 계산한 반응·확산 무늬 사이의 혼합 |
| 무늬 크기 | 1 | 흑백 무늬의 확대·축소 |
| 무늬 기준값 | 1 | 흑백 무늬를 두 색 영역으로 나누는 기준 |
| 줄무늬 늘이기 | 1 | 무늬의 세로 비율 |
| 경계 강조 | 1 | 두 색 영역 경계의 밝기 변화 |
| 작은 점 밀도 | 1 | 미세한 점을 추가하는 정도 |

완성된 날개 이미지를 복사하는 대신, 이 숫자로 무늬를 매번 다시 그립니다. 각 자손은 부모를 새로 뽑고, 숫자마다 임의의 혼합 비율을 적용해 가중평균을 만듭니다. 변이 때는 선택된 숫자에 작은 값을 더하거나 빼며, 드물게 새 값으로 바꿔 다양성을 남깁니다. 가장 높은 점수의 나방 한 마리는 그대로 보존합니다. 위장 점수는 평균 RGB 차이 `d`에서 `100 × exp(-d / 28)`로 계산하여 초기 점수가 상한에 몰리지 않게 했습니다.

이 구현은 [CamoEvo 논문](https://academic.oup.com/evolut/article/76/5/870/6881792)의 반응·확산 무늬, L*a*b* 색 좌표, 수치 유전자의 교차·변이 개념에서 영감을 받은 **교육용 단순화 모형**입니다. CamoEvo의 원본 코드나 실험 결과를 재현한 것은 아닙니다. 무늬 종류는 네 개의 미리 계산한 Gray–Scott 배열 사이에서 보간합니다. 위장 점수는 날개 표본의 RGB 값과 나무껍질 표본의 평균 차이를 교육용 함수로 변환합니다. 사람의 발견이나 새의 공격을 실제로 시뮬레이션하지 않습니다. 최고 점수가 전역 최적해라는 보장도 없습니다.

## GitHub Pages 게시

1. 이 폴더 전체를 GitHub 저장소의 기본 브랜치 루트에 올립니다. `.gitignore`는 로컬 원본 `1.py`를 제외합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 기본 브랜치와 **/(root)**를 선택해 저장합니다.
4. Pages 화면에 표시되는 주소에서 사이트를 엽니다.
